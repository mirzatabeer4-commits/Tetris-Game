\#  Tetris Game



A classic Tetris game developed using C# and Windows Presentation Foundation (WPF) as a Programming Fundamentals project.



\##  Features



\- Classic Tetris gameplay

\- Multiple block shapes (I, J, L, O, S, T, and Z)

\- Game grid with 22 rows and 10 columns

\- Upcoming block queue

\- Hold block feature

\- Keyboard-based controls

\- Sound effects

\- Game-over screen



\##  Technologies Used



\- C#

\- WPF (Windows Presentation Foundation)

\- .NET Framework

\- XAML

\- Visual Studio



\##  Project Structure



\- `App.xaml` and `App.xaml.cs` — Application startup.

\- `MainWindow.xaml` and `MainWindow.xaml.cs` — Main game window and interface.

\- `GameGrid.cs` — Game grid logic.

\- `GameState.cs` — Game state and gameplay management.

\- `Block.cs` — Base block functionality.

\- `IBlock.cs`, `JBlock.cs`, `LBlock.cs`, `OBlock.cs`, `SBlock.cs`, `TBlock.cs`, and `ZBlock.cs` — Different Tetris block shapes.

\- `BlockQueue.cs` — Upcoming block management.

\- `Position.cs` — Block position handling.

\- `Sound.cs` and `SoundManager.cs` — Sound effects and audio management.

\- `Assets/` — Game assets.

\- `Sounds/` — Sound resources.



\##  How to Run



1\. Download or clone this repository.

2\. Open `Tetris.sln` in Visual Studio.

3\. Allow Visual Studio to restore any required dependencies.

4\. Build the solution.

5\. Run the project.



\##  Project Objective



The objective of this project was to practice C# programming, object-oriented design, classes, game logic, and desktop application development.
